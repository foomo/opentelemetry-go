# API Reference

| Package | Import Path | Description |
|---|---|---|
| [glossytrace](/api/glossytrace) | `github.com/foomo/opentelemetry-go/exporters/glossy/glossytrace` | Styled terminal trace exporter with tree views and flamegraphs |
| [glossymetric](/api/glossymetric) | `github.com/foomo/opentelemetry-go/exporters/glossy/glossymetric` | Styled terminal metric exporter for Sum, Gauge, and Histogram data |
| [semconv](/api/semconv) | `github.com/foomo/opentelemetry-go/semconv` | Custom semantic convention attribute constructors |
| [oteltesting](/api/testing) | `github.com/foomo/opentelemetry-go/testing` | Test helpers for wiring OTel providers with automatic cleanup |
